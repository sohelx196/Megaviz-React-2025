Megaviz  ->  megaviz.co

MegaViz is a modern, responsive business website built using React and Tailwind CSS.
This project is a redesigned version of the original MegaViz HTML website, now converted into a scalable and component-based React application.

MegaViz is a company website that showcases:

Hero Section

Services

About Section

Testimonials

Contact Form

Responsive Navigation

Modern UI/UX Design

The goal of this project is to create a clean, fast, and scalable frontend using React best practices.



**Tech Stack

⚛️ React JS

🎨 Tailwind CSS

📩 FormSubmit (for contact form handling)

🌐 Responsive Design (Mobile + Desktop)**
